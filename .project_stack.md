# Правила стека технологий (Project Stack)

Настоящий Knowledge Item фиксирует архитектурный стек и глобальные решения для проекта "Семейная финансовая система". Все дальнейшие разработки должны строго следовать этим правилам.

## 1. Базовая архитектура
- **Frontend:** Раздельный SPA на базе Vite + React.
- **Backend:** Легковесный Node.js + Express API.

## 2. База данных и ORM
- **СУБД:** SQLite.
- **ORM:** Drizzle ORM.
- *Обоснование:* Максимальная легковесность, строгая типизация, полный контроль над SQL, 100% соответствие правилу Anti-Hype (избегание тяжеловесных фреймворков).

## 3. Стилизация (UI)
- **Технология:** Vanilla CSS (CSS Variables / Custom Properties).
- **Ограничения:**
  - Полный отказ от TailwindCSS (и любых сторонних CSS-фреймворков).
  - Minimalistic Styling: использование минимального количества цветов и стилей текста (Constraint of Means).
  - Spacing Hierarchy: разделение элементов исключительно за счет отступов (запрет на использование визуальных разделителей типа линий и теней).

## 4. Управление состоянием и Data Fetching
- **Инструменты:** TanStack Query (React Query) + React Context.
- **Логика работы:**
  - React Query используется для всего серверного стейта (кэширование API, графики, остатки по "Конвертам").
  - React Context используется исключительно для локального UI-стейта.

## 5. Валидация данных и API
- **Библиотека:** Zod.
- **Применение:** Создание единых (shared) схем валидации для фронтенда и бэкенда. Строгий контроль финансовых операций на входе (Zero Data Loss).
