# UI Registry

Реестр всех компонентов и стилей дизайн-системы "FullCup".

## Токены (Design Tokens)
Размещены в `design-tokens.css`. Отражают строгую базу:

**Colors (Backgrounds):**
- `--clr-bg-page` (основной фон страницы, белый), `--clr-bg-surface` (карточки, модалки, сайдбар, серый), `--clr-bg-accent`, `--clr-bg-semantic-success`, `--clr-bg-semantic-error` (Income и Expense склеены с Success и Error)

**Colors (Texts):**
- `--clr-text-primary`, `--clr-text-secondary`, `--clr-text-inverse`, `--clr-text-disabled`, `--clr-text-placeholder`, `--clr-text-semantic-success`, `--clr-text-semantic-error` (Income и Expense склеены с Success и Error)

**Colors (Controls & Borders):**
- `--clr-control-default` (основные контролы на странице, серый), `--clr-control-surface` (overlay контролы на карточках/сайдбаре, белый), `--clr-control-surface-hover` (ховер ячеек таблицы `m-editable-cell`, серый-100), `--clr-control-active`, `--clr-control-link`
- `--clr-border-primary`, `--clr-border-secondary`, `--clr-border-interactive`

**Metrics:**
- `--spc-0` до `--spc-80` (Fixed scale: 0, 2, 4, 8, 12, 16, 20, 24, 32, 40, 48, 64, 80)
- `--radius-xs` до `--radius-circle`
- Типографика: 2 заголовка `--font-size-h1` (32px / 40px) и `--font-size-h2` (22px / 28px); основной текст `--font-size-l` (24px / 36px), `--font-size-m` (18px / 24px), `--font-size-s` (16px / 24px); 2 начертания: `regular` (400) и `bold` (700). Статичные размеры (без адаптива).

## Атомы (Atoms)
Утилиты, размещены в `atoms.css`.

- **Layout:** `a-relative`, `a-flex`, `a-flex-col`, `a-items-center` и т.д.
- **Spacing:** `a-gap-*`, `a-px-*`, `a-py-*`
- **Typography:** `a-text-h1`...`a-text-m` и т.д.
- **Colors:** `a-clr-text-primary`, `a-bg-surface` и т.д.

## Молекулы (Molecules)
Базовые UI-блоки (`molecules.css`). 
*Правило: Молекулы поддерживают используемые контексты (normal, overlay) и необходимые фиксированные размеры. Все контролы не имеют ховер-эффекта (курсор pointer сохраняется), за исключением редактируемых ячеек таблицы.*

- `m-card`: Карточка (поддерживает normal и overlay контексты).
- `m-nav-item`: Элемент навигации (Links/Tabs). Без ховер-эффекта (курсор pointer). Начертание всегда `regular` (`var(--font-weight-regular)`), включая активное состояние (без layout shift).
- `m-tab`: Вкладки выбора (расходы/доходы, периоды и т.д.). Без ховер-эффекта (курсор pointer). Поддерживает фиксированные размеры `s`, `m`, `l` на основе текста s, m, l (`[data-size="s|m|l"]`, по умолчанию `m`). Начертание всегда `regular` (`var(--font-weight-regular)`), включая активное состояние (без layout shift).
- `m-operation-row`: Строка операции (`OperationRow`). Иконка категории слева, колонка суммы между иконкой и описанием с выравниванием чисел по правому краю (`m-operation-row-amount`, `text-align: right`, `tabular-nums`, `regular`), текстовое поле комментария с переносом (`ellipsis`), бейдж счёта. По умолчанию фиксированная ширина `5rem`, а внутри контейнера `.m-operation-list` ширина колонки суммы автоматически адаптируется под самый широкий элемент в списке через CSS Subgrid (`max-content`). Имеет высоту `calc(var(--line-height-m) + var(--spc-2))` и нижний отступ `padding-bottom: var(--spc-2)`. Поддерживает состояние добавления новой строки `[data-new="true"]` с бесшовной физической анимацией появления (`m-operation-row-enter`, 400ms `cubic-bezier(0.16, 1, 0.3, 1)`: плавное раскрытие высоты от 0 с нулевым начальным сдвигом сетки, мягкий fade-in прозрачности, сохранение стабильности базовой линии текста и сетки Subgrid без дёргания) и полной поддержкой `prefers-reduced-motion`. При передаче `onUpdate` поля становятся инлайн-редактируемыми: категория через нативный селект по клику на иконку, сумма через `EditableCell type="number"`, комментарий через `EditableCell type="text"` (при отсутствии комментария остается пустой инпут с плейсхолдером).
- `m-operation-list`: Контейнер списка операций с адаптивной сеткой колонок (CSS Subgrid). Автоматически подстраивает ширину колонки суммы под максимальную величину в списке, сохраняя строгое табличное выравнивание чисел по правому краю и отдавая всё оставшееся пространство под комментарий. Межстрочный интервал вынесен в строки для устранения скачков сеточных желобов (zero-gutter insertion).
- `m-button`: Кнопки (Primary, Secondary без обводки, Icon Danger, Icon нейтральная). Без ховер-эффекта (курсор pointer). Поддерживает фиксированные размеры `s` и `m`, текст внутри всегда размера `s` (`var(--font-size-s)`), начертание `regular` (`var(--font-weight-regular)`), без disabled-состояний. Варианты иконочных кнопок: `data-variant="icon-danger"` (удаление) и `data-variant="icon"` (нейтральные действия, сброс выбора).
- `m-input`: Текстовые поля, textarea и выпадающие списки (`select.m-input`, `button.m-input`). Без ховер-эффекта (курсор pointer у кнопок и селектов), поддерживает только размеры `m` и `s`, текст внутри всегда размера `s` (`var(--font-size-s)`), полностью без обводки во всех состояниях (`border: none`).
- `Dropdown`: Компонент выпадающего списка (обертка над `select.m-input`). Поддерживает размеры `m` и `s`, размер стрелки `ri-arrow-down-s-line` и текста `s`, отступ под стрелку (`padding-right: var(--spc-24)` для `s` и `var(--spc-32)` для `m`), полностью без обводки.
- `m-choice-list`, `m-choice-label`: Контейнеры радиокнопок и чекбоксов (`m-radio-control`, `m-checkbox-control`). Без ховер-эффекта (курсор pointer), фон контрола виден всегда (normal и overlay), полностью без обводки (`border: none`).
- `m-editable-cell`: Редактируемая ячейка таблицы (инпут, датапикер, селект). Максимально наследует оверлей-инпуты (`.m-input[data-context="overlay"]`): фон `var(--clr-control-surface)`, без обводки (`border: none`), скругление `var(--radius-m)`, текст размера `s` (`var(--font-size-s)`), мягкий ховер/фокус `var(--clr-control-surface-hover)`. Сохраняет отбивку разрядов сумм в фокусе, датапикер открывается по 1 клику без смены формата и скачков ширины, стрелочка селекта появляется при наведении, курсор-каретка строго у инпутов (`pointer` у селектов и датапикеров).
- `m-category-chip`: Кликабельный бейдж/чип категории для палитры выбора и фильтров. Поддерживает контексты normal, overlay, inverse и размеры s, m, l. Без ховер-эффекта (курсор pointer). Предаллоцированная прозрачная рамка 2px в обычном состоянии (без layout shift), активное состояние `[data-active="true"]` с контрастной обводкой 2px рамкой вместо заливки.
- `m-toast`: Компактное плавающее уведомление обратной связи (Undo/Redo). Фиксированное позиционирование внизу по центру экрана (`position: fixed`, `bottom: var(--spc-24)`), контрастный фон `var(--clr-bg-accent)`, цвет текста `var(--clr-text-inverse)`, отступы `var(--spc-8) var(--spc-16)`, скругление `var(--radius-m)`, текст `var(--font-size-s)`. Поддерживает интерактивную кнопку отмены `.m-toast-action` (Undo с подчеркиванием). Без теней и сдвигов разметки.
- `m-sync-indicator`: Индикатор внимания синхронизации с Google Таблицами в шапке приложения. Отображается **только** в ситуациях, требующих внимания пользователя: при сбое связи (красная точка `data-status="error"`) или незавершенной начальной выгрузке (серая точка `data-status="not_synced"`). В штатном режиме (`idle`, `saving`) или при ненастроенной таблице скрыт (`null`), сохраняя чистую шапку без визуального шума. По клику выполняет бесшовный переход в раздел настроек данных (`/settings/data`) с фокусом на поле ввода URL скрипта.

## Организмы (Organisms)
Крупные структурные блоки (`organisms.css`). 

- `o-page-layout`: Основная структурная оболочка страницы (верхний хедер и опциональный сайдбар справа). Полностью fluid без ограничений по ширине (`width: 100%`, без `min-width` и без `max-width`).
- `o-page-container` / `PageContainer`: Главный fluid-контейнер страницы (`PageContainer.jsx`). Свободно растягивается и сжимается без жестких лимитов. Поддерживает 2 варианта раскладки:
  - `single` (`variant="single"`): Одноколоночная раскладка на 100% доступной ширины (`1fr`). Используется для накоплений, кайф-баланса и дизайн-системы.
  - `two-column` (`variant="two-column"`): Двухколоночная раскладка с отступом `var(--spc-48)` (48px), где левая колонка fluid (`minmax(0, 1fr)`), а правая колонка имеет фиксированную ширину `20rem` (`320px`) для сводок, виджетов и списков (дашборд и страница всех операций). Содержит подкомпоненты `PageColumn` (`PageContainer.Column`) с `position="left" | "right"`.
- `o-header`: Основная навигация приложения с интеграцией индикатора синхронизации и баланса справа.

- `o-smart-entry` / `SmartTokenInput`: Контейнер умного ввода операций с инлайн-разметкой параметров в произвольном порядке. Блок ввода вместе с селектором даты размещен на компактной карточке поверхности (`.m-card.o-smart-entry-box[data-context="overlay"][data-size="s"]`), а внутренние компоненты функционируют в режиме `overlay` (`data-context="overlay"`: белое поле ввода `var(--clr-control-surface)`, белая кнопка выбора даты `.o-smart-date-btn`). Числа внутри поля ввода автоматически разбиваются по разрядам на лету (`15 000`, `1 000 000`) с бесшовным сохранением каретки и поддержкой `Backspace` через разрядные пробелы. Суммы подсвечиваются внутри текста: для расхода красным (`.o-smart-token-num[data-type="expense"]`: `color: var(--clr-text-semantic-error)`), для дохода зелёным (`.o-smart-token-num[data-type="income"]`: `color: var(--clr-text-semantic-success)`), знаки математики нейтральным цветом (`.o-smart-token-op`), без схлопывания чисел и без дописывания знака валюты в инпут. Поддерживает инлайн-бейджи категорий и счетов (`.m-category-chip.o-smart-token-chip[data-context="normal"]`) прямо на месте их ввода пользователем с кнопкой быстрого удаления. Дропдаун подсказок открывается при вводе букв (категории), сортирует категории по популярности за последний год (`sortCategoriesByPopularity`), динамически переключается на счета при совпадении с ними, а после выбора категории появляется только при считывании совпадения со счетами. Если слагаемых несколько, под инпутом внутри карточки отображается строка вычисленного итога (`.o-smart-entry-math-hint`: «1 500 + 300 = 1 800 ₽»). Справа от инпута расположен компактный селектор даты (`.o-smart-date-dropdown-container`) без знака календаря на кнопке, сохраняющий выбранную дату между последовательными операциями (sticky date). `Backspace` в пустом сегменте за бейджем моментально удаляет бейдж целиком.


- `o-investment-block`: Формы и списки для инвестиций.
- `o-chart-curve`: График в виде плавной кривой (Recharts).
- `o-data-table`: Систематизированная таблица данных с фиксированным layout (для списков операций и т.д.). Весь текст (заголовки `th` и ячейки `td`) строго размера `m` (`var(--font-size-m)`, 18px / 24px) и начертания `regular` (`var(--font-weight-regular)`). Текст ячеек всегда цвета `var(--clr-text-primary)` (без изменения на ховер). Колонка суммы (`.o-data-table-col-amount`) выровнена по правому краю. Поддерживает компактный режим `[data-compact="true"]` (используется на странице «Все операции»): ширина таблицы адаптируется под контент (`width: max-content; max-width: 100%`), высота однострочных строк 28px (`calc(var(--line-height-m) + var(--spc-4))`), межколоночный зазор `16px` (`padding: var(--spc-2) var(--spc-8)`). Поддерживает мультивыбор операций: узкая колонка чекбоксов `.o-data-table-col-checkbox` (2rem), выбор/снятие всех в шапке, выбор диапазона через Shift+Click (без выделения подложки строк). Все колонки пропорционально масштабированы: чекбокс `2rem`, сумма `7.25rem`, категория `10rem` с уходом текста под `...`, дата без года `4.75rem` ("18 окт"), колонка комментария `15.25rem` с переносом длинного текста до 2 строк (`-webkit-line-clamp: 2`), колонка кайфа с фиксированной шириной `10rem` (мультивыбор `BankMultiSelectCell` с переносом дополнительных пунктов и оверлеем чекбоксов), часть в банк `6.25rem` (`.o-data-table-col-bank-amount` с пустым состоянием при отсутствии счета). При многострочных ячейках все ячейки строки выравниваются по верхнему краю (`vertical-align: top`) по базовым линиям первых строк. Компактные инлайн-ячейки `m-editable-cell` и центрированные селекты без сдвигов верстки.
- `o-operations-filters` / `OperationsFilters`: Блок фильтрации операций на одной линии с отступами 20px (`var(--spc-20)`) между группами. Включает точный диапазон дат («С» и «По») с шириной инпутов, точно соответствующей длине саджестов пресетов снизу («Все», «Этот месяц», «Прошлый месяц», «Этот год»), мультиселект категорий с естественным русским склонением («X категорий») и компактную строку поиска без плейсхолдера с постоянной чёрной иконкой лупы (`var(--clr-text-primary)`).
- `o-operations-category-summary` / `OperationsCategorySummary`: Виджет распределения сумм по категориям в правой колонке страницы «Все операции». В обычном состоянии отображает счетчик найденных записей (`N записей`), идеально выровненный с шапкой таблицы `thead`, а в теле виджета наглядно показывает полоски категорий относительно максимальной величины (`(amount / maxAmount) * 100%`) со строкой «Итого» (`Σ`). При выборе 1 или более операций динамически пересчитывает сводку по выбранным записям, а снизу отображает компактную строку текстовых действий: «Дата» со стрелочкой выпадающего списка (вызывает дропдаун с пресетами «Прошлый месяц», «Сегодня», «Задать»), «Удалить» (с отменой через Undo / `Ctrl + Z`) и «Сбросить».
- `o-kaif-grid`: Двухколоночная адаптивная сетка счетов Кайф-баланса.
- `SettingsView`: Контейнер настроек (`SettingsView.jsx`) с двухуровневыми вкладками «Загрузка данных» и «Дизайн-система», активируемый по тройному нажатию «d» или по прямому URL `/settings`.
- `DataLoadView`: Экран загрузки данных и облачной синхронизации с Google Таблицами (`DataLoadView.jsx`). Включает первичный импорт базы в один клик, потабличный импорт из CSV, статус облачного зеркала Google Apps Script и резервный экспорт таблиц в CSV.
- `DesignSystemView`: Витрина токенов, молекул и организмов дизайн-системы («Дизайн-система»).
