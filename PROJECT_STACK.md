# Стек технологий и архитектура (Project Stack)

Настоящий документ фиксирует архитектурный стек, стандарты и глобальные инженерные решения для проекта **"FullCup" (Семейная финансовая система)**. Все разработки, доработки и взаимодействия AI-агентов строго следуют этим правилам.

---

## 1. Базовая архитектура (Local-First Monorepo)

Проект организован как легковесный монорепозиторий на базе **npm workspaces**:

- **`frontend/`**: Раздельный SPA на базе **Vite + React 19**.
- **`backend/`**: Легковесный **Node.js (v22+) + Express 5** REST API.
- **`shared/`**: Единый пакет правды (Single Source of Truth) для схем данных, валидаторов и общей бизнес-логики.
- **`scripts/`**: Утилиты резервного копирования, синхронизации и развертывания Google Apps Script.

---

## 2. База данных, ORM и Хранение

- **СУБД:** **SQLite** (библиотека `better-sqlite3`).
- **ORM:** **Drizzle ORM** (`drizzle-orm/better-sqlite3`).
- **Режимы БД:**
  - `journal_mode = WAL` (Write-Ahead Logging для высокой скорости и параллелизма чтения).
  - `foreign_keys = ON` (каскадная целостность реляционных связей).
  - `synchronous = NORMAL`, `temp_store = MEMORY`.
- **Отказоустойчивость:** Автоматические снимки безопасности (`pre_restore.db`) перед деструктивными операциями импорта.
- *Обоснование:* Максимальная легковесность, мгновенный старт, работа офлайн (Local-First), строгий контроль SQL, 100% соответствие принципу **Anti-Hype**.

---

## 3. Слой Shared (Единый источник правды)

Пакет `shared` подключается как во фронтенд, так и в бэкенд:
- **Drizzle Schema (`shared/schema.js`):** Описание таблиц `transactions`, `categories`, `banks`, `savings`, `transaction_banks`.
- **Zod Схемы (`shared/schemas/*`):** Валидация входных данных API и форм интерфейса (Zero Data Loss).
- **Чистая бизнес-логика (`shared/dateUtils.js`, `shared/splitBankAmount.js`):** Расчет периодов дат, сплиты сумм по счетам кайф-баланса.
- **Синхронизация (`shared/googleSheetsQueue.js`, `shared/googleSheetsUrl.js`):** Схлопывание очередей изменений и валидация URL вебхука.

---

## 4. Стилизация и Atomic Design

- **Технология:** **Vanilla CSS** (CSS Custom Properties). Полный отказ от TailwindCSS и сторонних UI-библиотек.
- **Архитектура стилей:**
  - `design-tokens.css` — палитра цветов, статичная типографика, фиксированная шкала отступов (`--spc-*`), радиусы.
  - `atoms.css` — утилитарные классы (`a-*`).
  - `molecules.css` — базовые молекулы (`m-*`, поддержка контекстов `normal`/`overlay` и фиксированных размеров `s`/`m`/`l`).
  - `organisms.css` — структурные блоки (`o-*`).
- **Ограничения:**
  - **Minimalistic Styling:** Ограничение средств (Constraint of Means), отсутствие лишних теней и декоративных рамок.
  - **Spacing Hierarchy:** Элементы разделяются исключительно отступами.
  - **Layout Stability:** Нулевые сдвиги макета (Zero Layout Shift) при ховерах и фокусах.
  - **No Hardcoding:** Запрещены произвольные пиксели и HEX-цвета вне токенов дизайн-системы.

---

## 5. Управление состоянием и Data Fetching

- **Серверное состояние:** **TanStack Query (React Query v5)** для всех данных API (кэширование, инвалидация, мутации, оптимистичные обновления).
- **Локальное состояние:** **React Context** (например, `OperationsHistoryContext` для отмены действий Undo/Redo) и нативные хуки (`useState`, `useReducer`).

---

## 6. Качество кода и тестирование (Quality Gate)

- **Линтер и форматтер:** **Biome** (`biome.json`).
  - Быстрая проверка: `npm run check` (enforced gate: 0 ошибок).
  - Автоматическое исправление: `npm run check:fix`.
- **Тестирование:** Встроенный нативный тест-раннер **Node.js Test Runner** (`node --test`).
  - Запуск тестов: `npm test`.
  - Покрывает критические утилиты: расчет дат, сплиты сумм, схлопывание очередей Google Sheets.

---

## 7. Резервное копирование и Облачная синхронизация

1. **Локальный CSV Бэкап:**
   - Экспорт всех таблиц: `npm run backup:export` (сохраняет в `backups/*.csv`).
   - Восстановление базы: `npm run backup:import` (с транзакционным откатом при сбое).
2. **Зеркало в Google Таблицах:**
   - Вебхук **Google Apps Script** (`scripts/google_apps_script.js`), развертываемый как Web App.
   - Фоновая синхронизация из интерфейса с накоплением и схлопыванием очереди изменений.
   - Ручной пуш/пулл через CLI: `npm run gsheets:push` и `npm run gsheets:pull`.

---

## 8. Сетевая конфигурация и порты

- **Frontend Dev Server:** `http://localhost:5173` (Vite dev server с автоматическим проксированием запросов `/api` на бэкенд).
- **Backend API Server:** `http://localhost:3001` (Express API с поддержкой CORS для локальной разработки).
